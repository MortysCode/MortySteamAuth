MORTY STEAM AUTH — БЫСТРЫЙ СТАРТ

1. Запустите MortySteamAuth.exe. Установка не требуется.
2. При первом запуске придумайте свой мастер-пароль (минимум 8 символов).
3. Добавьте аккаунт через Steam или импортируйте собственный maFile.
4. Крестик сворачивает приложение в трей. Правый клик по иконке открывает
   быстрые коды аккаунтов и кнопку полного выхода; левый клик возвращает окно.

ВАЖНО О БЕЗОПАСНОСТИ

- В архиве нет аккаунтов, паролей, сессий или maFiles автора приложения.
- Каждый пользователь создаёт отдельное зашифрованное хранилище в своём профиле Windows.
- Мастер-пароль не сохраняется и не может быть восстановлен.
- Храните резервные копии исходных maFiles и код восстановления отдельно.
- Пароль Steam используется только для входа в Steam и приложением не сохраняется.

Windows может показать предупреждение SmartScreen для самостоятельно собранного и
не подписанного сертификатом EXE. Передавайте архив только людям, которые знают его
источник, и сверяйте контрольную сумму при необходимости.
