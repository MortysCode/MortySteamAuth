# Morty Steam Auth

Windows-приложение на Rust для Steam Guard, зашифрованного хранения `maFile` и мобильных подтверждений.

## Возможности

- импорт отдельных `.maFile`/`.json`, папки или drag-and-drop;
- вход по логину и паролю Steam с поддержкой кода Steam Guard или подтверждения в текущем приложении;
- подключение нового мобильного аутентификатора и создание резервного `maFile`;
- перенос уже существующего аутентификатора по SMS;
- генерация Steam Guard-кода локально, без сетевых запросов;
- копирование кода одним кликом и таймер обновления;
- сворачивание в системный трей: правый клик показывает аккаунты и позволяет быстро скопировать код, левый возвращает окно;
- подтверждение и отклонение обменов, лотов торговой площадки, Steam Family и других mobile confirmations;
- подробности обменов: предметы, которые вы отдаёте и получаете, их изображения, названия, игры и количество, аватарка участника обмена;
- сворачиваемые списки предметов и меню массового принятия/отклонения трейдов и продаж для показанных подтверждений;
- подтверждение и отклонение запросов входа с показом устройства, IP и местоположения;
- поиск и удаление аккаунтов;
- AES-256-GCM-хранилище с ключом, полученным из мастер-пароля через Argon2;
- Steam-пароль не сохраняется; секреты и session-токены хранятся только внутри зашифрованного хранилища.

## Сборка EXE

1. Установите Rust с <https://rustup.rs> (вариант установки по умолчанию).
2. В PowerShell из папки проекта выполните:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
   ```

3. Готовый файл появится в `dist\MortySteamAuth.exe`.

Скрипт также создаёт `dist\MortySteamAuth-share.zip` — готовый архив для передачи друзьям.
В него входят только приложение и инструкция по первому запуску; пользовательские
аккаунты, пароли, сессии и локальное хранилище в архив не попадают. На другом
компьютере пользователь создаст собственное хранилище со своим мастер-паролем.

При первой сборке Cargo скачает зависимости, поэтому нужен интернет. Генерация Guard-кодов работает офлайн; вход, привязка и подтверждения требуют подключения к Steam.

Крестик скрывает приложение в системный трей. Чтобы полностью завершить процесс, нажмите правой кнопкой по иконке в трее и выберите `Выйти`.

## Где лежит хранилище

На Windows зашифрованный файл создаётся в локальной папке данных приложения (`%LOCALAPPDATA%\Morty\MortySteamAuth\data\vault.json`). Старое хранилище Steam Vault обнаруживается автоматически, поэтому после обновления данные не потеряются. Мастер-пароль не сохраняется. Если пароль потерян, расшифровать хранилище невозможно — храните резервные копии исходных `maFile` в безопасном месте.

## Авторизация после импорта maFile

Как и в SDA, импорт секретов и Steam-сессия — разные операции. После импорта откройте карточку аккаунта и нажмите `Войти в Steam` либо `Подтверждения`. Введите логин и пароль, затем код Steam Guard. Пароль не сохраняется; полученная сессия хранится внутри зашифрованного vault. После успешного входа кнопка на карточке изменится на зелёную `Сессия Steam OK`.

Если `maFile` был импортирован старой версией Morty Steam Auth (ранее Steam Vault), импортируйте тот же файл повторно: запись не продублируется, а будет дополнена `identity_secret`, SteamID из секции `Session` и стабильным `device_id` для подтверждений.

## Ограничения

- Поддерживаются `maFile`, где поле `shared_secret` присутствует в открытом Base64-виде.
- Для подтверждений импортированный `maFile` должен содержать `SteamID`, `identity_secret` и `device_id`; затем аккаунт нужно авторизовать кнопкой на его карточке.
- Steam не позволяет получить секрет уже подключённого аутентификатора только по паролю. Для такого аккаунта нужен импорт существующего `maFile` или перенос по SMS. После переноса Steam может временно ограничить обмены.
- Код восстановления `R.....` и экспортированный `maFile` нужно хранить отдельно: без них восстановление доступа может потребовать обращения в поддержку Steam.
- Точность кода зависит от системного времени Windows.
